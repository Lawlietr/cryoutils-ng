# Frequently Asked Questions
## General
### What is CryoUtils NG?
CryoUtils NG is a Steam Deck utility that manages swap files, swappiness, and memory parameters for improved gaming performance. It is a rewrite of the original [CryoUtilities](https://github.com/CryoByte33/steam-deck-utilities) by CryoByte33.

### Will this destroy my Steam Deck?
No known cases of this happening have been reported. If something does go wrong, please open an issue on GitHub.

### Does this work on Windows?
No. Windows does not allow tuning at this level of the kernel, with the exception of page file size, which is configurable through a GUI in Windows.

### Do these fixes affect battery life or increase heat generated by the Deck?
No, this does not directly affect fan speeds or battery life. However, by lifting a bottleneck, it could allow the CPU and GPU to work harder, which may technically raise fan speeds or lower battery life.

### Are there any downsides to these fixes?
Not known. At worst, performance is unchanged.

### Will updates revert these fixes/settings?
No, but reformatting the Deck will revert them. The tweaks have been tested across several SteamOS updates and remain in place after updates. If a future update does revert some settings, an update to this project will address it.

### What does X setting do?
See [the tweak explanation page](docs/tweak-explanation.md) for details on each parameter.

## Swap/Swappiness
### What games benefit from the larger swap file?
Any game that uses a combined 16 GB for RAM and VRAM will likely benefit from the swap fix. The degree of improvement depends on asset compression, asset size, and memory churn.

### Do the swap changes work for all games?
Yes. They apply to any program on SteamOS loaded from **any** location, including applications installed on external storage, provided the trigger conditions are met.

### Are there any situations where the swap fix isn't a good option?
No, as long as swappiness is also tuned properly.

### Does the swap fix hurt emulators?
No. Emulators such as Yuzu and Cemu have also benefited from these fixes.

### Will the swap fix hurt my SSD?
No. Using a lower swappiness value completely offsets the additional writes from a larger swap file, and actually helps preserve SSD longevity.

### How much SSD wear does the stock configuration cause?
A swappiness of 100 causes the kernel to prefer swapping to disk before filling RAM. Because of this, a large percentage of memory operations would wear the SSD. The default wear pattern is estimated to reduce SSD lifespan to approximately 4 years of average gameplay on modern titles.

Setting swappiness to 1 does not prevent all swapping, but it limits it to cases where the Deck has exhausted its total memory.

### Do differently-sized SSDs have a performance difference for swapping?
Yes. Read and write speeds both affect swap performance and therefore overall performance. Valve selected quality parts with relatively similar speeds to ensure a consistent experience across models.

In general, larger SSDs are faster, but there is more to it than capacity alone.

## Memory Tuning
### What performance differences can I expect from these tweaks?
In general, gameplay will be noticeably smoother. FPS averages may also improve in games where the CPU is the bottleneck.

### Is there any risk to applying these settings?
Not known. All of these parameters are built into the Linux kernel; the tweaks only adjust pre-existing values rather than adding or changing functionality.
